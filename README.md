# Christ's Love Ministries International — Website

Static website for [christloveministriesinternational.org](https://www.christloveministriesinternational.org), hosted on Vercel.

## Structure

```
public/               ← the website (this is what gets deployed)
  index.html          ← home page (hero slideshow, YouTube playlists, convention section)
  <page>/index.html   ← one folder per page, e.g. public/about-us/index.html → /about-us
  assets/site.css     ← shared styles (header, nav, footer, WhatsApp bubble)
  assets/media/       ← all images (self-hosted)
  assets/video/       ← background/promo videos
  convention-2026/    ← the Annual Convention slideshow embedded on the home page
tools/
  server.js           ← local dev server:  node tools/server.js  → http://localhost:8123
  generate.js         ← page generator (rebuilds public/<page>/ from tools/spec/*.json)
  spec/               ← layout data extracted from the original site
```

## Working on the site

- **Run locally:** `node tools/server.js` then open http://localhost:8123 — no dependencies, no build step.
- **Edit the home page:** edit `public/index.html` directly.
- **Edit other pages:** you can edit each `public/<page>/index.html` directly. They were generated by
  `node tools/generate.js` from the layout specs — if you re-run the generator it will overwrite
  direct edits to those files, so once you start editing pages by hand, stop using the generator.
- **Header / footer / nav** for the generated pages live in `tools/generate.js`
  (`headerHtml` / `footerHtml`) — or just find-and-replace across `public/*/index.html`.
- Pages use a fixed 1512 px design canvas (`<meta name="viewport" content="width=1512">`),
  matching the original desktop layout on every device.

## Deploying

Connected to Vercel: every push to `main` deploys automatically.
Config in `vercel.json` (static deploy of `public/`, no build).
